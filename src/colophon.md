<p>This site is the Book of Brendan Ngwa Nforbi, published at bookofbrendan.blog. Pages are written in Markdown and built as a static book.</p>

<ul>
  <li>Body text is set in Archivo. The wordmark and code are IBM Plex Mono.</li>
  <li>The palette is duotone — warm gray in light and dark — with a gold accent for Scripture and the feed.</li>
  <li>Meditations live as Markdown files and are published as HTML, RSS, and JSON, all authored by <a href="{{ site.author.path }}">Brendan Ngwa Nforbi</a>.</li>
  <li>The home of this book is bookofbrendan.blog.</li>
</ul>
