<p>This site is a static book. Pages are written in Markdown and built with <a href="https://www.11ty.dev/">Eleventy</a>.</p>

<ul>
  <li>Body text is set in Archivo. The wordmark and code are IBM Plex Mono.</li>
  <li>The palette is duotone — warm gray in light and dark — with a gold accent for Scripture and the feed.</li>
  <li>Meditations live as Markdown files and are published as HTML, RSS, and JSON.</li>
  <li>The intended home of this book is <a href="https://bookofbrendan.blog">bookofbrendan.blog</a>.</li>
</ul>
